# 🕳️ 科学护眼助手 (Eye Care Assistant)

这是一个轻量级、非侵入式的科学护眼助手。它基于著名的 **20-20-20 护眼法则**（每工作 20 分钟，向 20 英尺外远眺 20 秒以上），帮助长期面对电脑工作的用户保护视力。

---

## 🌟 核心特色

- **🕳️ 非侵入式“黑洞提醒”**：
  工作时间超限后，屏幕上会随机生成一个小黑洞，缓慢旋转变大，并利用**引力透镜扭曲算法**吞噬和拉伸周围的文字和图像，提醒你该休息了。相比弹窗打断，它更加温和、渐进、非侵入。
- **💤 智能休息识别（零打扰）**：
  你不需要点击任何“开始休息”按钮。只要你放下鼠标、离开键盘，助手检测到无输入状态达到设定时间后，黑洞便会慢慢消失，并自动重置并开启下一轮的工作计时。
- **🔋 后台极低资源占用**：
  - 基于操作系统底层 API 钩子（Event Hooks）进行输入监控，空闲时几乎不占用 CPU（< 0.1%）。
  - 黑洞动画使用 NumPy 进行局部像素矩阵运算，只渲染黑洞周围的小区域，避免全屏截图或绘制，保证 30 FPS 流畅度的同时极大节省 GPU 与 CPU 开销。
- **📦 单文件运行**：
  已打包为单个可执行文件（`.exe`），无任何外部图片和动态库依赖，双击即用。

---

## 🛠️ 安装与使用

### 1. 运行编译好的 EXE
1. 在 `dist` 目录下找到 `护眼助手.exe`。
2. 双击运行即可。

### 2. 操作说明
- **后台托盘**：运行后程序无主窗口，会自动最小化至系统托盘（屏幕右下角）。
- **查看进度**：鼠标悬停在托盘图标上，可以悬浮查看“剩余工作时间”或“连续休息时间”。
- **右键菜单**：右键点击托盘图标，可以：
  - 查看当前状态
  - 打开 **设置** 面板修改各项参数
  - 手动 **重置计时**
  - **退出程序**
- **黑洞消失**：当黑洞出现后，只要**停止操作鼠标和键盘持续达到设定时间**（默认 20 秒），黑洞即会自动消失，并重置工作倒计时。如果在未满时间前移动鼠标，黑洞会继续存在并增长。

---

## ⚙️ 设置面板参数

在托盘右键菜单中选择 `设置...`，可以调整以下参数：
1. **工作时长**：连续工作的时长（分钟，默认 20 分钟）。
2. **休息时长**：判定为彻底休息并重置计时所需要保持静止的累计时间（秒，默认 20 秒）。
3. **判定空闲时间**：键盘鼠标多久没有动作才开始算作“开始休息”（秒，默认 5 秒）。
4. **黑洞最大半径**：黑洞能长到的最大尺寸（像素，默认 350px）。
5. **黑洞生长速度**：黑洞每帧变大的像素数（默认 0.8 像素/帧）。

## 💻 开发者编译说明

如果你想从源码运行或重新打包，可以参考以下步骤：

### 依赖项
- Python 3.8+
- 库依赖：`PyQt6`, `pynput`, `mss`, `Pillow`, `numpy`, `pyinstaller`

### 步骤
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 直接运行：
   ```bash
   python main.py
   ```
3. 编译打包：
   ```bash
   python build_exe.py
   ```
   编译成功后，生成的单文件绿色版程序将保存在当前目录下的 `dist/护眼助手.exe` 中。
